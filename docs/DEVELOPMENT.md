# 칼퇴의 유혹 · 개발 및 유지보수

[← 프로젝트 소개](../README.md)

`index.html`을 Chrome 또는 Edge에서 열면 실행됩니다. 설치, 빌드, 인터넷 연결이 필요하지 않습니다. 다른 PC에는 **index.html 한 개만** 옮기면 됩니다. `verify.cjs`와 이 문서는 개발·검증용이며 실행 의존성이 아닙니다.

## 플레이

- 17:59:30부터 18:00:00까지 30초를 생존하면 정시 퇴근 성공입니다.
- 내려오는 방향 알림의 중심이 초록색 판정선에 닿을 때 해당 방향키를 누릅니다.
- **오른쪽 동료 접근 → `←` 왼쪽으로 회피 / 왼쪽 동료 접근 → `→` 오른쪽으로 회피.** 화살표는 동료 위치가 아니라 내 이동 방향입니다.
- `↑` 팔을 들어 결재 서류를 막고 위로 튕겨내기 / `↓` 시선 피해 모니터 밑으로 숙이기.
- 상단 `전체화면`으로 화면을 확대합니다. `화면 복원` 또는 Esc로 나옵니다. 브라우저에서 지원하지 않으면 일반 Chrome/Edge에서 열거나 F11을 사용합니다.
- 판정 시각 전후 300ms 이내면 회피할 수 있습니다. 정확한 입력은 PERFECT, 나머지는 GOOD입니다.
- 판정 시간 안에서 잘못된 방향을 누르거나, 알림을 놓치면 미스입니다. 누적 3회면 즉시 야근 확정입니다.
- 너무 일찍 누른 키는 예약하지 않습니다. 판정할 알림이 없을 때의 입력으로 라이프를 잃지는 않습니다.
- 키를 누르고 있는 자동 반복은 무시합니다. 같은 키를 다시 쓰려면 떼었다가 누릅니다.
- 다른 창으로 이동하면 자동 일시정지됩니다. 돌아온 뒤 재개 버튼을 눌러 이어갑니다.
- 소리 및 움직임 줄이기는 상단 버튼으로 조절합니다. 움직임 줄이기는 OS 설정을 처음에 따르며, 버튼으로 직접 바꿀 수 있습니다. 켜면 화면 흔들림, 동료의 큰 접근 이동, 서류 회전·날아가기, 엔딩 이동·색종이를 줄입니다. 대신 접근 위치, 회피 자세, 방어와 반사 결과를 정지된 자세로 보여줍니다. 판정용 알림의 이동·속도·난이도는 같습니다.

## 5단계 리듬 난이도

시작·결과 화면의 플레이어 선택에서 젊은 남성(셔츠·넥타이), 젊은 여성(블라우스·포니테일)을 고를 수 있습니다. 선택은 같은 창에서 재시작할 때 유지됩니다. 왼쪽 동료는 여성, 오른쪽 동료는 남성, 파티션 뒤 인물은 흰머리와 주름이 있는 연장자입니다.

캐릭터는 머리·몸통·팔꿈치·무릎·손발로 구성합니다. 회피는 준비→발 디딤→체중 이동→복귀, 방어는 팔 들기→충돌 반동→서류 반사 순서입니다. 관절은 두 뼈 IK로 연결하고 연속 회피는 현재 자세에서 이어집니다. 퇴근은 2.2초 동안 이동 거리에 맞춰 발을 디디고 팔을 교차로 흔들며 출구로 이동합니다. 결과창은 동작이 끝난 뒤 표시합니다.

시작·결과 화면에서 난이도를 선택합니다. 다시 시작하면 선택한 단계가 유지되며, 일시정지 중에는 바꿀 수 없습니다. 플레이 중 우측 상단에 현재 단계와 BPM이 표시됩니다.

| 단계 | 이름 | BPM | 업무 알림 간격 |
| --- | --- | --- | --- |
| 1 | 여유롭게 | 60 | 1,000ms |
| 2 | 가볍게 (기본) | 80 | 750ms |
| 3 | 바쁘게 | 100 | 600ms |
| 4 | 아슬아슬 | 120 | 500ms |
| 5 | 칼퇴 전쟁 | 150 | 400ms |

단계가 올라가면 알림 발생 빈도와 판정선까지 내려오는 속도가 함께 빨라집니다. 동료·서류의 접근도 같은 속도에 맞춥니다. 모든 단계에서 30초, 라이프 3, 첫 판정 전 2.25초의 준비 시간은 같습니다. 속도표는 스크립트 상단 `DIFFICULTY_LEVELS`에서 관리합니다.

## 판정 여유 A/B 테스트

`index.html`의 `<script>` 시작 부분에 있는 다음 값 하나만 변경합니다.

```js
const DIFFICULTY_CONFIG = Object.freeze({
  HIT_WINDOW_MS: 300 // A: 300, B: 200
});
```

단위는 밀리초이며 목표 시각 **전후 각각** 적용됩니다. 300은 총 600ms, 200은 총 400ms의 판정 범위입니다. A/B 비교 시 선택 난이도는 동일하게 유지하세요. 고속 단계에서 인접 판정 범위가 겹치면 현재 시각과 가장 가까운 알림 하나를 판정합니다. 누른 방향에 유리한 알림을 골라주는 방식은 아닙니다.

성공 결과에 생존 시간, 회피 횟수, PERFECT 횟수, 최대 콤보를 표시합니다. A/B별 20회 사람 플레이 테스트는 [TEST_REPORT.md](../TEST_REPORT.md)의 기록표로 별도 진행할 수 있습니다. 자동 시뮬레이션은 실제 사용자 난이도 평가를 대체하지 않습니다.

## 구성 및 유지보수

단일 HTML 내부에 CSS → UI 마크업 → 난이도 설정 → 순수 게임 로직 `EscapeGame` → 저장소 복구 → Web Audio → 입력·시간 제어 → Canvas 렌더링 순서로 배치했습니다.

- 시간은 `performance.now()` 기반 단일 rAF 루프로 관리합니다. 재시작해도 루프나 리스너를 추가하지 않습니다.
- 250ms보다 긴 메인 스레드 지연도 자동 일시정지 처리해 갑작스러운 연속 미스를 방지합니다.
- 완료한 알림은 즉시 제거하며, 시각 효과는 최근 사건 한 개만 보관합니다.
- 소리는 회피 성공, 피격, 성공, 실패 사건에서만 발동합니다. 박자마다 소리를 내는 BGM/메트로놈은 없습니다.
- 외부 이미지, 음원, 폰트, 라이브러리, 네트워크 API를 사용하지 않습니다.

## 기록 저장

`localStorage` 키: `escape_1800_best`

```json
{ "bestTime": 0, "clearCount": 0 }
```

`bestTime`은 0~30초, `clearCount`는 0 이상의 안전한 정수입니다. JSON 문법뿐 아니라 타입과 범위도 검사합니다. 손상되면 기본값으로 복원합니다. 읽기/쓰기가 차단된 시크릿 창이나 브라우저에서도 현재 창의 메모리 기록으로 계속 실행됩니다. 저장 불가 상태를 화면에 표시합니다. `file:` URL의 저장 지속 여부는 브라우저 정책에 따라 달라질 수 있습니다.

## 개발 검증

Node.js가 있다면 저장소 루트 폴더에서 `node verify.cjs`를 실행합니다. Node는 검증에만 사용하며 게임에는 필요하지 않습니다. 상세 검증 범위와 남은 수동 확인은 [TEST_REPORT.md](../TEST_REPORT.md)에 있습니다.
